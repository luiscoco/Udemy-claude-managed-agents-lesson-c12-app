Understand the concepts, follow the source code, and verify the application yourself.

What you will learn

1Independent cleanup deadline

Do not reuse an aborted run signal. Trace the rule in the architecture walkthrough and compare the displayed evidence.

2Interrupt acknowledgement is not a stop

Rescheduling is not settled. Trace the rule in the architecture walkthrough and compare the displayed evidence.

3Confirm idle or terminated

Archive only after confirming idle. Trace the rule in the architecture walkthrough and compare the displayed evidence.

Executes a cleanup state machine with authored provider statuses. No remote interrupt or archive is issued by the local mode. Each run starts from a fresh local seed. The run journal stores results, not production workflow state.

How to run this application

1Install Node.js and open the application folder

Use Node.js 24 or later. From the repository root, install the locked dependencies.

node --version
npm ci

2Create your local .env file

No API key is required for the local experiment. Optional live commentary requires your own API key, agent ID and environment ID. It explains the local result; it does not activate the integration discussed in the lesson. Copy the example and edit the new file in your editor. The real .env is ignored by Git.

Copy-Item .env.example .env
notepad .env

3Prepare resources or choose the local path

For the optional live path, set your API key, then run npm run setup if you do not already have resource IDs. The script creates the environment before a text-only agent, saves each ID immediately, and reuses IDs already configured. It uses CLAUDE_MODEL or the source default; choose a model available to your account. An uncertain network failure may have created a resource: inspect your account before retrying.

4Start the application

Run the command below and wait for the printed server URL. Open http://127.0.0.1:3012. The terminal stays open while the server is running. If PORT differs, use that value instead.

npm start

5Run and inspect the evidence

Select the first scenario, inspect its editable fields, press Run experiment, and compare the outcome and evidence with the table above. Select another scenario to investigate the boundary condition.

6Verify and stop

Run the source checks below in a second terminal. Stop the web server with Ctrl+C. Local journal records are not production workflow state. Closing a browser tab does not confirm remote cancellation.

npm test

Create and understand .env

Copy the example rather than renaming it. Put your own values in .env; leave .env.example safe for sharing. Restart the server after changing configuration. PORT controls the local URL. An empty optional model value uses the source default.

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MANAGED_AGENT_ID=your_agent_id
CLAUDE_MANAGED_ENVIRONMENT_ID=your_environment_id
PORT=3012
